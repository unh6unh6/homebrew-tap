# homebrew-tap

Homebrew casks by unh6unh6.

| Cask | 설명 | 설치 |
|---|---|---|
| [SpaceSwitcher](https://github.com/unh6unh6/SpaceSwitcher) | 데스크탑(Space)에 이름을 붙이고 Option+E로 전환 | `brew install --cask unh6unh6/tap/spaceswitcher` |
| [Session Monitor](https://github.com/unh6unh6/session-monitor) | 여러 Claude Code 세션의 상태를 메뉴바에서 그룹별로 확인 | `brew install --cask unh6unh6/tap/session-monitor` |

업데이트: `brew upgrade --cask <cask>`

두 앱 모두 자체 서명이고 공증을 받지 않았습니다. 이 tap으로 설치하면 처음 실행이 막히지 않도록 설치 과정에서 격리 표시를 지웁니다.
